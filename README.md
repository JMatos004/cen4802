## Tennis Score Tracker

A small Java web application that runs locally and allows a user to enter two tennis players and their current game scores. The application uses Java's built-in HTTP server and contains application logic to determine whether the set is tied or which player is currently leading.

## Requirements

- Java 17 or newer
- Git

## Run

From the project directory:

```bash
javac -d out src/TennisScoreApp.java
java -cp out TennisScoreApp
```

Then open:

http://localhost:8080

## Version Control

This project was developed using a GitHub feature-branch workflow. The initial version was committed to `main`, an enhancement was developed on a feature branch, and the change was merged back into `main` through a pull request.
